## 🚀 Locally Run Karna (Apne Computer Par)

### Step 1 — Python Install Check
```bash
python --version
```
Python 3.8+ honi chahiye.

### Step 2 — Streamlit Install Karo
```bash
pip install streamlit nltk
```

### Step 3 — Is folder mein jao
```bash
cd text_mining_chatbot
```

### Step 4 — Chatbot Run Karo
```bash
streamlit run chatbot.py
```

Browser mein automatically khul jayega: `http://localhost:8501`

## 🌐 Streamlit Cloud par Deploy Karna (FREE)

### Step 1 — GitHub Account Banao
https://github.com

### Step 2 — New Repository Banao
- "New repository" click karo
- Name: `text-mining-chatbot`
- Public rakho
- Create Repository

### Step 3 — Files Upload Karo
- `chatbot.py` upload karo
- `requirements.txt` upload karo

### Step 4 — Streamlit Cloud par Jao
https://share.streamlit.io

### Step 5 — Deploy
- "New app" click karo
- Apna GitHub repo select karo
- Main file: `chatbot.py`
- "Deploy!" click karo

✅ 2-3 minute mein aapka chatbot live ho jayega!
Free URL milegi jaise: `https://yourname-text-mining-chatbot.streamlit.app`
